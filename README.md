# Oluwatobi Olaopa — Portfolio

Personal portfolio site: growth strategy, performance marketing, digital marketing and marketing analytics.
Founder of [Revynex](https://revynex.io).

It is a single static page (`index.html`) with no build step. Brand logos are inlined as SVG, and fonts load from Google Fonts.

## Host it for free

### Option 1: GitHub Pages (simplest)
1. In this repository, go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose branch **main** and folder **/ (root)**, then click **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Netlify or Vercel
Import this repository, leave the build command empty and set the publish/output directory to the repository root.

### Custom domain (optional)
You can point a domain such as `oluwatobi.revynex.io` or `oluwatobiolaopa.com` at either host from its domain settings.

## Share on LinkedIn
- **Profile → Add profile section → Recommended → Add featured → Add a link**, and paste the site URL.
- Also add it under **Contact info → Website** (type: Portfolio).

## CV
The "Download CV" buttons link to `Oluwatobi-Olaopa-CV.pdf`. To update your CV, replace that file with a new PDF of the same name.

## Editing
All content lives in `index.html`. Search for the text you want to change and edit it directly.
